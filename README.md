# پنل پیامک (smsbot)

برنامهٔ تحت وب برای فروشنده‌های اشتراک که با پنل **3X-UI (نسخهٔ ۳ به بعد)** کار می‌کنن:

- **مدیریت کانفیگ‌ها** بدون رفتن به پنل: ساخت، تمدید، فعال/غیرفعال، صفر کردن مصرف، حذف، لینک و QR
- **ثبت شمارهٔ مشتری** کنار هر کانفیگ
- **هشدار خودکار پیامکی** وقتی حجم یا تاریخ اشتراک داره تموم می‌شه
- **پیام همگانی** (الان یا زمان‌بندی‌شده)
- پیامک‌ها از **خط شخصی خودت** فرستاده می‌شن (گوشی اندروید + اپ رایگان SMS Gateway)

## نصب

با SSH وارد سرور (اوبونتو یا دبیان) شو و این یک خط رو بزن:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/alikaidkhordeh/smsbot/main/install.sh)
```

اگه برای برنامه دامنه ساختی (مثلاً `sms.example.com`)، این‌طوری بزن تا آدرس کامل رو هم نشون بده:

```bash
SMSBOT_DOMAIN=sms.example.com bash <(curl -Ls https://raw.githubusercontent.com/alikaidkhordeh/smsbot/main/install.sh)
```

آخر کار **آدرس برنامه و رمز ورود** رو نشون می‌ده.

- **روی یه سرور جدا از پنل** (مثلاً سرور ربات‌ها): بعد از ورود، تو تنظیمات ← «اتصال به پنل» آدرس کامل پنل
  (مثل `https://panel.example.com:2053/abc123/`) و نام کاربری و رمز پنل رو بده و «وصل شو» رو بزن.
  برنامه یه توکن مخصوص خودش تو پنل می‌سازه و رمز پنل رو ذخیره نمی‌کنه.
- **روی همون سرور پنل**: نصب‌کننده خودش تنظیمات پنل رو می‌خونه و وصل می‌شه.

بقیهٔ کارها (اتصال گوشی، متن‌ها، ساعت ارسال، دامنه و پورت) همه داخل خود برنامه‌ست.

## باز شدن مثل برنامه روی گوشی (بدون نوار آدرس)

برای این کار برنامه باید با **https** باز بشه. راحت‌ترین راه کلادفلره:

۱. تو کلادفلر یه رکورد DNS از نوع A بساز، مثلاً `sms.yourdomain.com` به آی‌پی سرور برنامه، با **ابر نارنجی (Proxied)**.
۲. حالت SSL/TLS کلادفلر **Flexible یا Full** باشه، هر دو کار می‌کنه (برنامه روی یه پورت هم http جواب می‌ده هم https). فقط «Full (strict)» نه.
۳. نصب‌کننده پورت برنامه رو یکی از پورت‌هایی می‌ذاره که کلادفلر پشتیبانی می‌کنه (۸۴۴۳، ۲۰۸۳، ۲۰۸۷، ۲۰۵۳، ۲۰۹۶ یا ۴۴۳).
   آدرس می‌شه `https://sms.yourdomain.com:8443`. برای حذف `:8443` از آدرس: Rules ← Origin Rules ← Hostname برابر دامنه ← Destination Port رو بکن پورت برنامه.
۴. آدرس رو تو Chrome گوشی باز کن ← منوی ⋮ ← «نصب برنامه». از این به بعد با آیکون خودش، مثل یه اپ باز می‌شه.

## وصل کردن گوشی (یک‌باره)

۱. اپ **SMS Gateway for Android** رو از [sms-gate.app](https://sms-gate.app/) روی گوشی نصب کن.
۲. اجازهٔ ارسال پیامک رو بهش بده و بهینه‌سازی باتری اپ رو خاموش کن.
۳. تو صفحهٔ اول اپ، **Cloud Server** رو روشن کن و دکمهٔ «Offline» رو بزن تا «Online» بشه.
۴. نام کاربری و رمزی که اپ نشون می‌ده رو تو برنامه ← تنظیمات ← اتصال گوشی وارد کن و «پیامک آزمایشی» بزن.

## دستورهای کمکی

| کار | دستور |
|---|---|
| آپدیت | از داخل برنامه: تنظیمات ← «بررسی و نصب آپدیت» (یا همون دستور نصب) |
| رمز جدید (اگه فراموش شد) | `bash <(curl -Ls https://raw.githubusercontent.com/alikaidkhordeh/smsbot/main/install.sh) reset-password` |
| حذف برنامه | `bash <(curl -Ls https://raw.githubusercontent.com/alikaidkhordeh/smsbot/main/install.sh) uninstall` |
| دیدن لاگ | `journalctl -u smsbot -f` |

اطلاعات (شماره‌ها و تنظیمات) تو `/opt/smsbot/data` ذخیره می‌شه و با آپدیت پاک نمی‌شه.

## ساختار

- `server/` ـ سرور برنامه (پایتون ۳.۸ به بعد، بدون هیچ کتابخونهٔ اضافه)
- `web/` ـ صفحه‌ها (HTML/CSS/JS ساده)
- `install.sh` ـ نصب‌کننده و سرویس systemd
- `tests/smoke.py` ـ تست کامل بعد از نصب (در GitHub Actions با پنل واقعی 3X-UI اجرا می‌شه)
